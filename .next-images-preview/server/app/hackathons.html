A 48-hour sprint playbook

Before · Prepare

Have starter templates, a Docker setup and a security checklist ready.

0–4 h · Scope and model

Agree on one problem, sketch the data model and split the work.

4–20 h · Build a vertical slice

Connect one working React screen to an API and database.

20–36 h · Integrate and automate

Add seed data, scripts and tests so manual steps are repeatable.

36–44 h · Security pass

Review input validation and access checks in the running app.

44–48 h · Demo

Rehearse the problem, walkthrough and next steps.

After · Retro

Write down what worked and one thing to improve next time.
