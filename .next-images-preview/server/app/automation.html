Six rules for automation I trust

01

Automate the check, not the decision

Send exceptions to a person with the evidence attached.

02

Log every run

If it cannot be audited, it cannot be trusted.

03

Safe to run twice

Make retries idempotent so they do not duplicate a payment.

04

Fail loudly

A silent failure is worse than no automation at all.

05

Keep rules in config

A regulation change should not require rewriting the application.

06

Measure the savings

Track exceptions caught and hours returned.
