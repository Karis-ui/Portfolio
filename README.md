# Charles Macharia Kariuki — Portfolio

A React portfolio built with the Next.js App Router. The home page contains the
hero and overview; each portfolio section has its own route and is accessible
from the responsive sidebar.

## Routes

- `/` — Hero and overview
- `/security` — Security approach
- `/lab` — Browser-only simulated security lab
- `/automation` — K-Trace workflow and time-savings estimator
- `/engineering` — Technology stack and development principles
- `/projects` — Project case studies
- `/certifications` — Credentials
- `/trends` — Industry trends
- `/hackathons` — Hackathon and CTF approach
- `/about` — Background and interests
- `/contact` — Contact details and email form

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Run the production build with `npm run build`.
